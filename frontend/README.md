# 记账小助手前端

基于Web技术的前端应用，支持iOS快捷指令和Android PWA。

## 技术栈

- **Web技术**：HTML5 + CSS3 + JavaScript ES6+
- **PWA技术**：Service Worker + Manifest
- **设计风格**：移动优先，响应式设计

## 功能特性

- 用户认证（登录、注册）
- 交易管理（添加、查看）
- 统计分析（汇总、趋势）
- 家庭管理（创建、成员管理）
- 版本切换（本地/服务端）
- 离线支持（PWA特性）

## 快速开始

### 本地开发

1. 克隆项目
```bash
git clone <repository-url>
cd jizhang1/frontend
```

2. 启动本地服务器
```bash
# 使用Python启动简单HTTP服务器
python -m http.server 8000

# 或使用Node.js
npx serve -p 8000
```

3. 访问应用
```
http://localhost:8000
```

### 配置后端API

1. 打开应用
2. 进入"设置"标签
3. 修改"API基础URL"为实际的后端地址
4. 保存设置

## PWA安装

### iOS Safari
1. 在Safari中打开应用
2. 点击"分享"按钮
3. 选择"添加到主屏幕"
4. 确认添加

### Android Chrome
1. 在Chrome中打开应用
2. 点击"添加到主屏幕"提示
3. 确认添加

## 功能使用

### 用户认证
- **注册**：填写用户名、邮箱、密码
- **登录**：使用邮箱和密码登录
- **退出**：清除本地存储的认证信息

### 交易管理
- **添加交易**：填写日期、金额、分类等信息
- **查看交易**：在"交易"标签查看所有交易
- **快速添加**：点击右下角"+"按钮快速添加

### 统计分析
- **查看统计**：在"统计"标签查看汇总数据
- **数据展示**：总支出、交易笔数、平均每笔、最高支出

### 家庭管理
- **创建家庭**：在"家庭"标签创建新家庭
- **查看成员**：查看当前家庭成员列表

### 设置
- **API配置**：设置后端API地址
- **退出登录**：清除认证信息

## 离线支持

PWA支持离线使用，数据存储在本地：
- 交易数据临时缓存
- 用户认证信息本地存储
- 设置配置本地保存

## 响应式设计

应用适配不同屏幕尺寸：
- **手机**：单列布局
- **平板**：双列布局
- **桌面**：多列布局

## 安全措施

- HTTPS传输（生产环境）
- JWT认证
- 本地数据加密存储
- 敏感信息保护

## 故障排查

### PWA无法安装
- 检查HTTPS配置
- 验证manifest.json路径
- 检查Service Worker注册

### API连接失败
- 检查API URL配置
- 验证网络连接
- 查看后端服务状态

### 数据不同步
- 检查认证token是否过期
- 验证网络连接
- 清除本地缓存重试
