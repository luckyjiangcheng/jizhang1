# 图标占位符文件

实际使用时，请替换为真实的图标文件。

## 图标要求

- **尺寸**：192x192, 512x512
- **格式**：PNG
- **透明度**：支持透明背景
- **设计**：简洁、易识别

## 推荐设计

1. **主要元素**：
   - 钱包图标
   - 账本图标
   - 简化的"记"字

2. **颜色方案**：
   - 主色：#007aff（蓝色）
   - 背景：白色或透明
   - 对比：确保在各种背景下清晰可见

3. **风格**：
   - 扁平化设计
   - 简洁线条
   - 适当圆角

## 生成工具

- **在线工具**：Canva, Figma, Sketch
- **AI生成**：Midjourney, DALL-E, Stable Diffusion
- **图标库**：Flaticon, Icons8, Noun Project

## 文件命名

- icon-192.png (192x192)
- icon-512.png (512x512)
