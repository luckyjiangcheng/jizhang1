# AI记账小助手产品使用文档（含用户 QA）

## 1. 产品简介

AI记账小助手是一套基于 iPhone 快捷指令与在线服务的智能记账工具，支持：

- 语音/文本快速记账
- 在线账单存储与查询
- dashboard 报表查看
- 用户后台管理与授权码能力

- 快捷指令 2（日常使用）：`https://www.icloud.com/shortcuts/61d6776543b749779afed65fadb00fca`

- 登录地址：`http://39.107.253.44/`
- 默认密码规则：手机号后六位

首次登录后请立即修改密码。

## 3. 新用户使用流程

### 步骤 1：安装快捷指令

在 iPhone Safari 中打开上述两个 iCloud 链接，依次点击“添加快捷指令”。

说明：

- 第一个快捷指令用于安装环境，安装时需要输入授权码
- 第二个快捷指令用于日常记账与查询

### 步骤 2：登录后台

打开 `http://39.107.253.44/`，使用手机号与默认密码（后六位）登录。

### 步骤 3：完成基础配置

- 确认账号与授权码状态正常
- 在快捷指令中配置服务地址为 `http://39.107.253.44`（服务端口 80）
- 按 iPhone 设置快捷手势：设置 → 辅助功能 → 触控 → 轻点背面 → 双击，绑定“AI记账小助手旗舰版”
- 完成一次测试记账

### 步骤 4：开始日常记账

在快捷指令中输入或说出消费内容，例如：

- “昨天晚上打车 35 元”
- “今天午饭 28 元”
- “买水果花了 20 元”

系统会识别并写入账单。

### 步骤 5：查看报表

通过快捷指令读取 dashboard CSV 数据并打开可视化页面，查看消费趋势与分类占比。

## 4. 账号与安全建议

- 默认密码仅用于首次登录，请立刻修改
- 不在群聊公开授权码、账号、密码
- 仅在可信网络环境下登录后台
- 定期检查账号登录情况与账单记录

## 5. 用户常见 QA

### Q1：登录不上后台怎么办？

A：

- 确认访问地址是否为 `http://39.107.253.44/`
- 确认手机号输入正确
- 默认密码是手机号后六位
- 若仍失败，联系管理员重置密码

### Q2：快捷指令提示网络超时怎么办？

A：

- 检查手机网络是否可用
- 检查快捷指令中的服务地址是否是 `http://39.107.253.44`（端口 80）
- 稍后重试，若持续失败联系管理员检查服务状态

### Q3：安装器提示授权失败怎么办？

A：

- 确认输入的授权码是否完整、无空格
- 确认授权码状态为可用（未禁用、未失效）
- 若提示已使用，请联系管理员重新发放授权码

### Q4：为什么说“买了一个苹果”被分错类？

A：

- “苹果”存在语义歧义（水果/品牌）
- 建议说法更明确：如“买水果苹果 10 元”
- 系统已增加餐饮类优先规则，但建议描述更具体

### Q5：账单写入成功，但我看不到数据？

A：

- 确认使用的是同一个授权码链路
- 确认查询接口与写入接口环境一致
- 尝试刷新 dashboard 数据后重新打开

### Q6：忘记密码怎么办？

A：

- 联系管理员重置密码
- 重置后使用新密码登录，并及时修改为个人强密码

### Q7：是否支持多设备使用？

A：

- 支持，但建议同一账号在可信设备使用
- 若多设备并发使用，请确保网络稳定，避免重复提交

### Q8：数据安全吗？

A：

- 账单数据通过服务端保存与管理
- 建议管理员定期备份数据库并启用访问控制策略
