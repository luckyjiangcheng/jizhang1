# AI记账小助手操作手册（快捷指令版）

本手册用于指导你完成从安装快捷指令、授权码激活、日常记账到 dashboard 展示的完整流程。

## 0. 版本导航

- V1（单机本地方案，非接口存储）：`docs/v1_guide.md`
- V2（接口在线存储方案，授权码驱动）：`docs/v2_guide.md`

## 1. 准备事项

- 设备：iPhone（已安装“快捷指令”App）
- 网络：可访问你的后端服务地址（例如 `http://localhost:8000` 或公网域名）
- 账号：已由管理端创建用户，并拿到对应授权码
- 建议：iCloud Drive 已开启（便于快捷指令读写文件）

## 2. 快捷指令安装步骤（详细）

### 步骤 1：允许安装非官方快捷指令

- 打开 iPhone：设置 → 快捷指令
- 打开“允许不受信任的快捷指令”
- 若系统没有该开关，先运行一次任意系统快捷指令后再回来开启

### 步骤 2：安装三条快捷指令

- 安装“AI记账小助手安装器”
- 安装“AI记账小助手”
- 安装“AI记账小助手账单”

### 步骤 3：首次运行安装器

- 打开“AI记账小助手安装器”
- 首次弹窗权限全部选择“允许”
- 输入后端 API 地址（示例：`https://api.xxx.com`）
- 输入授权码并点击继续

### 步骤 4：安装校验与激活

安装器会按以下顺序调用接口：

1. 安装前可用性检查（是否可安装）
2. 安装激活（首次激活成功后标记为 used）

如果授权码状态不是 `unused`，安装会被拒绝并提示原因。

### 步骤 5：绑定快捷入口

- 方式 A：Siri 语音（“嘿 Siri，记账”）
- 方式 B：轻点背面（设置 → 辅助功能 → 触控 → 轻点背面）
- 方式 C：操作按钮（iPhone 15 Pro+）
- 方式 D：桌面快捷指令小组件

## 3. 日常记账流程

### 3.1 发起记账

- 运行“AI记账小助手”
- 说出消费内容，例如：
  - “午餐 32 元”
  - “打车 45 元”
  - “咖啡 19 元”

### 3.2 写入逻辑

- 快捷指令将金额、分类、备注等字段与授权码一起提交
- 服务端按授权码找到所属账号后写入交易
- 每条交易都关联 `license_code_id` 与 `user_id`

## 4. 账单与 Dashboard 查看

### 4.1 清单查询（JSON）

- 运行“AI记账小助手账单”
- 传入授权码
- 服务端返回该授权码关联手机号下“所有授权码”的聚合交易清单（按时间倒序）

### 4.2 Dashboard 数据（CSV）

- 同样传入授权码
- 服务端返回 dashboard 可直接消费的 CSV
- CSV 字段顺序固定：
  - `Date, Time, Amount, Category, Item, Merchant, Notes, LicenseCode, Phone`

## 5. 接口清单（给快捷指令对接）

- 安装可用性检查  
  - `POST /api/v2/shortcut/install/check`
- 安装激活  
  - `POST /api/v2/shortcut/install/activate`
- 记账写入  
  - `POST /api/v2/shortcut/transactions`
- 聚合清单（JSON）  
  - `GET /api/v2/shortcut/transactions/dashboard?license_code=...`
- 聚合清单（CSV）  
  - `GET /api/v2/shortcut/transactions/dashboard.csv?license_code=...`

## 6. 推荐的快捷指令交互顺序

1. 用户输入授权码
2. 调用 `install/check`
3. 若 `allowed=true`，调用 `install/activate`
4. 安装成功后进入日常记账
5. 每次记账调用 `shortcut/transactions`
6. 查看报表时调用 `dashboard`（JSON）或 `dashboard.csv`

## 7. 常见问题与排障

### Q1：提示“授权码不可安装”

- 可能原因：授权码已使用或已禁用
- 处理：
  - 联系管理端发放新授权码
  - 或在管理端检查该码状态

### Q2：提示“授权码未激活”

- 可能原因：跳过了安装激活步骤
- 处理：重新运行安装器，确保调用激活接口成功

### Q3：记账成功但账单为空

- 检查是否查询了正确的后端地址
- 检查是否使用同一授权码链路
- 检查服务器时间与本地时间差异是否导致过滤范围问题

### Q4：CSV 无法在 dashboard 显示

- 检查是否使用 `dashboard.csv` 接口
- 检查 CSV 表头是否被二次改写
- 确保快捷指令未删除字段列

## 8. 运维建议

- 管理端需保留“授权码发放、禁用、删除、查询”日常操作流程
- 生产环境建议开启 HTTPS，避免授权码明文泄露
- 建议为快捷指令增加失败重试（网络超时场景）
