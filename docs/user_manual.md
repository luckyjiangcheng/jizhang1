## 🚀 快速开始

### 安装流程

记账小助手 采用 **“零配置”** 安装方案，您不需要任何编程知识，也无需注册任何账号。

#### 第一步：安装“配置助手” (安装器)

请在 iPhone 上点击此链接：
👉 **[点击安装 记账小助手安装器](https://www.icloud.com/shortcuts/记账小助手安装器)**

1.  点击 **“添加快捷指令”**
2.  运行 **`记账小助手安装器`**
3.  它会自动：
    - 下载并配置 AI 服务（使用开发者预设的 Key，无需您输入）
    - 创建账本文件
    - **自动弹出主程序安装界面**

#### 第二步：安装“主程序” (记账小助手)

当上一步自动弹出（或手动点击下方链接）时：
👉 **[点击安装 记账小助手](https://www.icloud.com/shortcuts/记账小助手)**

1.  点击 **“添加快捷指令”**
2.  **完成！** 🎉

## 📱 功能使用

### 🎙️ 语音记账

最自然的记账方式，适合日常小额消费。

1.  **唤醒方式**：
    - 对着 Siri 说：**“嘿 Siri，记账小助手”**
    - 直接点击桌面图标
    - 使用背面轻拍或操作按钮（详见下方高效调用指南）
2.  选择 **“语音记账”**
3.  **说出消费内容**，例如：
    - “刚才打车花了35块”
    - “今天中午吃饭用了88元”
    - “买了一杯咖啡25元”
4.  **确认信息**：
    - AI 会显示识别结果，点击 **“确认”** 后会立即保存并关闭确认页
    - 随后会收到提示：**“✨ 记账成功！已存入账本”**
    - 点击 **“取消”** 会直接关闭确认页，不写入账本

### 📷 截图记账

适合大额消费或有详细小票的场景。

1.  **准备截图**：在支付完成界面（如微信支付/支付宝），**截屏**
2.  运行 **记账小助手**，选择 **“截图记账”**
3.  **确认信息**：
    - AI 会自动识别小票上的金额、商户等信息
    - 点击 **“确认”** 后会立即保存并关闭确认页
    - 随后会收到提示：**“✨ 记账成功！已存入账本”**
    - 点击 **“取消”** 会直接关闭确认页，不写入账本

### 📊 查看账单

直观了解您的消费情况和财务状况。

1.  运行 **记账小助手**，选择 **“查看账单”**
2.  **查看内容**：
    - **消费概览**：本月总支出、笔数、平均每笔金额
    - **分类分布**：消费类别饼图，了解钱花在哪里
    - **支出趋势**：每日/每周/每月支出变化曲线
    - **交易明细**：按时间降序排列的详细交易记录
3.  **时间筛选**：点击顶部标签切换查看今天、本周、本月、本年的数据
4.  **排序方式**：可选择按时间或金额排序交易明细

## ⚡️ 高效调用指南

为了让记账像呼吸一样自然，推荐您设置以下快捷方式：

### 1. Siri 语音调用

最快捷的唤醒方式，适合任何场景。

*   **设置**：确保您的设备已启用 Siri
*   **使用方法**：
    - 对着 iPhone 说：**“嘿 Siri，运行 记账小助手”**
    - 或长按侧边按钮（iPhone X 及以上）或 Home 按钮（旧款 iPhone）激活 Siri，然后说：**“运行 记账小助手”**
*   **快捷指令**：您还可以为 记账小助手 设置更简短的 Siri 指令
    - **设置路径**：设置 → Siri 与搜索 → 快捷指令 → 选择 记账小助手 → 编辑 Siri 短语
    - **示例**：设置为“记账”，这样您只需说“嘿 Siri，记账”即可唤醒

### 2. 背面轻拍 (Back Tap)

最适合单手操作的调用方式。

*   **设置路径**：设置 → 辅助功能 → 触控 → 轻点背面
*   **操作**：选择“轻点两下”或“轻点三下”，勾选 **记账小助手**
*   **使用**：在任意界面轻拍手机背面，即可唤醒记账

### 3. 操作按钮 (Action Button)

iPhone 15 Pro 及以上机型专属。

*   **设置路径**：设置 → 操作按钮
*   **操作**：滑动选择“快捷指令”，点击下方选择框，勾选 **记账小助手**
*   **使用**：长按侧边操作按钮即可唤醒

### 4. 桌面小组件 (Home Screen Widget)

直观的桌面入口。

*   **操作**：长按桌面空白处 → 点击左上角 `+` 号 → 搜索 **"快捷指令"**
*   **选择**：拖动 **记账小助手** 图标到桌面
*   **使用**：点击桌面图标即可运行

## 📁 数据管理

### 账本位置

您的所有交易数据都存储在：
- **iCloud Drive/Shortcuts/记账小助手/记账小助手.csv**

### 数据安全

1.  **本地存储**：账本文件仅存储在您自己的 iCloud Drive 中，开发者无法查看
2.  **隐私保护**：AI 识别过程仅发送文本/图片给大模型服务商，不留存任何个人数据
3.  **数据备份**：iCloud 会自动备份您的账本文件

### 数据迁移

*   **换手机**：只要登录同一个 iCloud 账号，重新下载快捷指令即可，数据会自动同步
*   **导出数据**：您可以直接在 iCloud Drive 中找到 `记账小助手.csv` 文件，下载到电脑进行备份或分析

## 🎯 高级功能

### 智能分类

记账小助手 会自动将您的消费归类到以下类别：

- 🥘 **餐饮美食**：外出就餐、外卖、零食、饮料等
- 🚗 **交通出行**：公交、地铁、打车、加油等
- 🛍️ **购物消费**：服装、电子产品、日用品等
- 🏠 **居家生活**：房租、水电费、物业费等
- 🎮 **休闲娱乐**：电影、游戏、旅游、健身等
- 🎁 **人情往来**：红包、送礼、请客等
- 🏥 **医疗健康**：看病、买药、体检等
- 📚 **教育培训**：学费、书籍、课程等
- 💰 **金融贷款**：房贷、车贷、信用卡还款等
- ❤️ **孝敬父母**：给父母生活费、礼物等
- 💼 **工作商务**：办公用品、差旅、商务招待等
- 📦 **其他支出**：无法明确归类的支出

### 语音识别优化

为了获得更好的识别效果，建议您：
- 清晰说出消费金额和类别
- 例如：“今天中午吃饭花了88元”、“打车去机场花了50元”
- 避免模糊表达，如：“买了点东西”、“花了一些钱”

## ⚠️ 常见问题

**Q: 我的数据安全吗？**
A: 非常安全。
- 您的账本仅存储在您自己的 iCloud Drive 中
- AI 识别过程不留存任何个人数据

**Q: 需要付费吗？**
A: 目前开发者免费提供 API 服务供您体验。

**Q: 换手机了怎么办？**
A: 只要登录同一个 iCloud 账号，重新下载快捷指令即可，数据会自动同步。

**Q: 识别结果不准确怎么办？**
A: 您可以在确认页面手动修改识别结果，然后再点击确认。

**Q: 支持哪些语言？**
A: 目前仅支持中文语音和中文小票识别。
