# ZenLedger 用户极速安装手册

欢迎使用 ZenLedger，您的 AI 财务助理。
本产品采用 **“零配置”** 安装方案，您不需要任何编程知识，也无需注册任何账号（直接使用开发者提供的服务）。

---

## 🚀 30秒安装流程

您只需要点击下方两个链接，即可完成所有安装。

### 第一步：安装“配置助手” (Installer)

请在 iPhone 上点击此链接（模拟链接，需替换为真实链接）：
👉 **[点击安装 ZenLedger Installer](https://www.icloud.com/shortcuts/ZenLedger_Installer)**

1.  点击 **“添加快捷指令”**。
2.  运行 **`ZenLedger Installer`**。
3.  它会自动：
    *   下载并配置 AI 服务（使用开发者预设的 Key，无需您输入）。
    *   创建账本文件。
    *   **自动弹出主程序安装界面**。

### 第二步：安装“主程序” (ZenLedger)

当上一步自动弹出（或手动点击下方链接）时：
👉 **[点击安装 ZenLedger](https://www.icloud.com/shortcuts/example_main_app)**

1.  点击 **“添加快捷指令”**。
2.  **完成！** 🎉

## 📱 如何使用

### 🎙️ 记一笔 (语音)
1.  对着 Siri 说：**“嘿 Siri，ZenLedger”**（或者直接点击桌面图标）。
2.  选择 **“语音记账”**。
3.  说出消费内容，例如：“刚才打车花了35块”。
4.  **确认信息**：AI 会显示识别结果，点击 **“确认”** 后自动记账。

### 📷 拍一张 (截图)
1.  在支付完成界面（如微信支付/支付宝），**截屏**。
2.  运行 **ZenLedger**，选择 **“截图记账”**。
3.  **确认信息**：AI 会显示识别到的金额和商户，点击 **“确认”** 后自动入账。

### 📊 查账单
1.  运行 **ZenLedger**，选择 **“查看账单”**。
2.  即可看到本月的消费饼图和预算曲线。

## ⚡️ 高效调用指南

为了让记账像呼吸一样自然，推荐您设置以下快捷方式：

### 1. 背面轻拍 (Back Tap)
最适合单手操作的调用方式。
*   **设置路径**：设置 -> 辅助功能 -> 触控 -> 轻点背面。
*   **操作**：选择“轻点两下”或“轻点三下”，勾选 **ZenLedger**。
*   **使用**：在任意界面轻拍手机背面，即可唤醒记账。

### 2. 操作按钮 (Action Button)
iPhone 15 Pro 及以上机型专属。
*   **设置路径**：设置 -> 操作按钮。
*   **操作**：滑动选择“快捷指令”，点击下方选择框，勾选 **ZenLedger**。
*   **使用**：长按侧边操作按钮即可唤醒。

### 3. 桌面小组件 (Home Screen Widget)
直观的桌面入口。
*   **操作**：长按桌面空白处 -> 点击左上角 `+` 号 -> 搜索 **"快捷指令"**。
*   **选择**：拖动 **ZenLedger** 图标到桌面。
*   **使用**：点击桌面图标即可运行。

## ⚠️ 常见问题

**Q: 我的数据安全吗？**
A: 非常安全。
1.  您的账本 (`ZenLedger.csv`) 仅存储在您自己的 **iCloud Drive** 中，开发者无法查看。
2.  AI 识别过程仅发送文本/图片给大模型服务商，不留存任何个人数据。

**Q: 需要付费吗？**
A: 目前开发者免费提供 API 服务供您体验。

**Q: 换手机了怎么办？**
A: 只要登录同一个 iCloud 账号，重新下载快捷指令即可，数据会自动同步。
