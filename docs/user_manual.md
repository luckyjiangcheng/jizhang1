# ZenLedger 用户极速安装手册

欢迎使用 ZenLedger，您的 AI 财务助理。
本产品采用 **“零配置”** 安装方案，您不需要任何编程知识，也无需注册任何账号（直接使用开发者提供的服务）。

---

## 🚀 30秒安装流程

您只需要点击下方两个链接，即可完成所有安装。

### 第一步：安装“配置助手” (Installer)

请在 iPhone 上点击此链接（模拟链接，需替换为真实链接）：
👉 **[点击安装 ZenLedger Installer](https://www.icloud.com/shortcuts/example_installer)**

1.  点击 **“添加快捷指令”**。
2.  运行 **`ZenLedger Installer`**。
3.  它会自动：
    *   下载并配置 AI 服务（使用开发者预设的 Key，无需您输入）。
    *   创建账本文件。
    *   **自动弹出主程序安装界面**。

### 第二步：安装“主程序” (ZenLedger)

当上一步自动弹出（或手动点击下方链接）时：
👉 **[点击安装 ZenLedger](https://www.icloud.com/shortcuts/example_main_app)**

1.  点击 **“添加快捷指令”**。
2.  **完成！** 🎉

## 📱 如何使用

### 🎙️ 记一笔 (语音)
1.  对着 Siri 说：**“嘿 Siri，ZenLedger”**（或者直接点击桌面图标）。
2.  选择 **“语音记账”**。
3.  说出消费内容，例如：“刚才打车花了35块”。
4.  AI 会自动记账并语音确认。

### 📷 拍一张 (截图)
1.  在支付完成界面（如微信支付/支付宝），**截屏**。
2.  运行 **ZenLedger**，选择 **“截图记账”**。
3.  AI 会自动识别金额和商户并入账。

> **进阶技巧**：您可以将 ZenLedger 设置为 iPhone 的 **“轻点背面”** 触发，实现真正的无感记账！
> (设置 -> 辅助功能 -> 触控 -> 轻点背面 -> 轻点两下 -> 选择 ZenLedger)

### 📊 查账单
1.  运行 **ZenLedger**，选择 **“查看账单”**。
2.  即可看到本月的消费饼图和预算曲线。

## ⚠️ 常见问题

**Q: 我的数据安全吗？**
A: 非常安全。
1.  您的账本 (`ZenLedger.csv`) 仅存储在您自己的 **iCloud Drive** 中，开发者无法查看。
2.  AI 识别过程仅发送文本/图片给大模型服务商，不留存任何个人数据。

**Q: 需要付费吗？**
A: 目前开发者免费提供 API 服务供您体验。

**Q: 换手机了怎么办？**
A: 只要登录同一个 iCloud 账号，重新下载快捷指令即可，数据会自动同步。
