# 记账小助手 V1 版本安装与使用文档（单机本地方案）

## 1. 版本定义

V1 是单机本地方案（非接口在线存储），核心特征：

- 不依赖后端 API
- 以本地文件驱动展示与交互
- 主要使用 `confirm` 与 `dashboard` 模板文件
- 适合离线演示、单人本地使用、无服务端场景

## 2. V1 保留范围

V1 需要保留以下资源与能力：

- `public/confirm.txt`
- `public/dashboard.txt`
- `src/confirm.txt`
- `src/dashboard.txt`

说明：

- `public/*` 用于静态发布目录
- `src/*` 用于源模板编辑与构建输入

## 3. 适用对象

- 无后端部署能力的个人用户
- 需要快速本地体验产品流程的测试人员
- 需要确认 UI/文案/CSV 展示逻辑的设计同学

## 4. 安装流程（V1）

### 步骤 1：准备文件

确保本地项目中存在：

- `public/confirm.txt`
- `public/dashboard.txt`

可选：同步检查 `src/confirm.txt` 与 `src/dashboard.txt`。

### 步骤 2：安装快捷指令（V1）

安装以下快捷指令（按实际发布链接）：

- 记账小助手安装器（V1）
- 记账小助手（V1）
- 记账小助手账单（V1）

### 步骤 3：运行安装器

首次运行安装器时：

- 允许文件访问（iCloud Drive/本地文件）
- 允许快捷指令读写目标目录
- 完成初始化配置（如账本 CSV 路径）

### 步骤 4：验证基础能力

- 可打开确认页（confirm）
- 可写入本地 CSV
- 可打开 dashboard 并看到数据

## 5. 数据流说明（V1）

V1 数据流：

1. 用户在快捷指令中输入/语音识别消费内容
2. 写入本地 CSV（通常在 iCloud Drive）
3. `dashboard.txt` 读取 CSV 进行展示
4. 所有数据保留在用户本地，不经过服务端 API

## 6. 常见目录建议

- 账本 CSV：`iCloud Drive/Shortcuts/记账小助手/记账小助手.csv`
- 模板文件：`public/confirm.txt`、`public/dashboard.txt`

## 7. V1 验收清单

- 安装后可正常运行记账快捷指令
- 确认页可展示并完成提交流程
- CSV 可持续追加记录
- dashboard 可解析 CSV 并展示图表/列表
- 断网状态下基础流程可运行

## 8. 常见问题

### Q1：dashboard 无数据

- 检查 CSV 路径是否正确
- 检查 CSV 表头是否与模板预期一致
- 检查快捷指令是否有文件读写权限

### Q2：confirm 页面无法提交

- 检查快捷指令回调动作是否存在
- 检查字段命名是否被手动修改
- 检查是否误用了 V2 的网络动作节点

### Q3：换手机后数据丢失

- 确认是否登录同一 iCloud 账号
- 确认目标 CSV 在 iCloud 已同步完成

## 9. 与 V2 的边界

- V1：本地 CSV、无后端依赖、单机优先
- V2：在线 API、授权码机制、多设备/聚合能力

建议：

- 继续保留 V1 用于离线与轻量场景
- 新功能优先在 V2 演进，V1 仅做必要兼容维护
