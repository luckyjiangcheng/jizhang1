# UI 交互优化 CheckList

## 基础设计系统
- [x] 采用 Violet/Indigo 主色调，深色/浅色模式切换自然
- [x] 字体排版（SF Pro / Roboto）清晰，字号层级分明
- [x] 阴影与圆角统一，符合 Material 3 或 iOS Human Interface Guidelines
- [x] 按钮（Button）、输入框（Input）、卡片（Card）样式一致且有交互反馈

## 导航与布局
- [x] 移动端显示底部 Tab Bar（首页、交易、记账FAB、统计、设置）
- [x] 桌面端显示左侧 Sidebar，内容区域自适应
- [x] 页面切换流畅（Fade/Slide Transition），无闪烁

## 首页（仪表盘）
- [x] 顶部展示“总资产/月收支”卡片，金额清晰
- [x] 快捷入口（记一笔、查预算、看报表）
- [x] 预算告警卡片（仅当超支时显示）
- [x] 最近 5 笔交易摘要列表

## 交易列表
- [x] 交易按日期分组（Header 显示日期 + 当日收支小计）
- [x] 单笔交易项展示：分类图标、商户/备注、金额（红/绿）、时间
- [x] 列表支持下拉刷新（Pull-to-refresh，可选）或加载更多
- [x] 无数据时显示友好的 Empty State

## 统计分析
- [x] ECharts 图表配色与应用主题一致，Dark Mode 适配
- [x] 饼图展示分类占比，柱状图展示收支趋势
- [x] 提供时间范围切换（本周/本月/本年）

## 预算与家庭
- [x] 预算展示为进度条卡片（颜色区分健康/预警/超支状态）
- [x] 家庭成员列表展示头像、角色，支持邀请操作
- [x] 设置页聚合个人信息、家庭管理、预算设置、API配置

## 认证与 PWA
- [x] 登录/注册页全屏背景与居中卡片，表单验证即时反馈
- [x] PWA 安装提示（Install Prompt）与离线状态提示

## 性能与体验
- [x] 所有数据请求展示骨架屏（Skeleton Loading）
- [x] 操作成功/失败展示 Toast 提示
- [x] 错误边界处理（网络错误、API 异常）友好展示
