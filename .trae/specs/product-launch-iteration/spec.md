# 产品发布迭代规格说明书 (Product Launch Iteration Spec)

## 为什么 (Why)
用户准备将产品推广给大众使用，需要进一步优化用户体验、界面美观度和数据准确性。重点在于降低调用门槛、增加记账确认机制、提供更丰富且符合中文习惯的统计报表，并修复日期识别逻辑。

## 变更内容 (What Changes)
- **文档更新**:
  - `docs/user_manual.md`: 增加“高效调用指南”（如背面轻拍、操作按钮、桌面小组件）。
  - `docs/developer_distribution_guide.md`: 更新快捷指令逻辑，增加“确认/修改”步骤。
- **Dashboard 重构**:
  - `src/dashboard.txt`: 完全中文化，实现“日、周、月、年”四个维度的统计与对比（环比/同比）。
  - UI 风格：清爽自然，中文显示。
- **Prompt 优化**:
  - `src/prompt.txt`: 增强对“今天”、“昨天”等相对日期的处理逻辑，确保日期准确性。
- **快捷指令逻辑变更 (需在文档中体现)**:
  - 增加“提取结果确认”步骤：用户在写入 CSV 前可以预览并修改数据。

## 影响范围 (Impact)
- **Affected specs**: `dashboard-redesign` (将被本 spec 覆盖).
- **Affected code**: `src/dashboard.txt`, `src/prompt.txt`, `docs/*.md`.

## 新增需求 (ADDED Requirements)

### 需求：快捷调用指南
系统文档应包含如何设置 iOS“背面轻拍”、“操作按钮”或“桌面小组件”的教程，以便用户一键唤起记账。

### 需求：记账确认机制
在写入 CSV 之前，系统应展示提取到的数据（日期、金额、分类、事项），并允许用户：
1.  **确认**: 直接写入。
2.  **修改**: 修改文本后写入。

### 需求：多维度中文统计看板
Dashboard 必须支持以下 Tab 页，且所有指标均为中文：
- **今天 (Today)**: 实时消费，对比昨天同时间段（或全天）。
- **本周 (Week)**: 本自然周消费，对比上周。
- **本月 (Month)**: 本自然月消费，对比上月。
- **本年 (Year)**: 本自然年消费，对比去年。
- **图表**:
  - 分布图 (饼图/环图): 按“类目”统计。
  - 趋势图 (柱状/折线): 按时间粒度统计。
  - 明细表: 包含 时间、类目、事项、金额 (¥, 2位小数)。

## 修改需求 (MODIFIED Requirements)

### 需求：日期智能识别
**修改**: Prompt 必须能够根据传入的 `Current Date` 准确解析“今天”、“昨天”、“前天”等相对时间词，或者从图片/文本中提取绝对日期。
**规则**:
- 输入中有具体日期 -> 使用该日期。
- 输入中有“昨天” -> `Current Date` - 1天。
- 输入中无时间 -> 使用 `Current Date`。
- 输出格式严格为 `YYYY-MM-DD`。

### 需求：Dashboard 样式
**修改**: 移除英文界面，全部替换为中文。移除旧的筛选器逻辑，改为固定维度的 Tab 切换（日/周/月/年）。

## 移除需求 (REMOVED Requirements)
无。
